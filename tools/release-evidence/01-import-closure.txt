THE THREE TRAPS IN THE BRIEF, EACH RESOLVED
1. DYNAMIC import() — the token badge. web/tokens.js:21 does
     const mod = await import('../src/surface/tokens.js');
   inside try/catch. That file IS shipped. It then fails on its OWN bare
   'js-tiktoken' specifier, the outer catch swallows it, and the badge shows its
   no-encoder state. Shipping it makes the failure the intended tested path
   instead of an unexpected 404, and web/app.js names it unconditionally. 3.1 KB.
2. A SECOND dynamic import the brief did not mention:
     src/surface/gui/controller.js:33  const mod = await import('./renderer.js');
   src/surface/gui/renderer.js DOES NOT EXIST anywhere in this repo.
   `ls src/surface/gui` returns only controller.js. A 404 is therefore the
   designed "renderer unresolvable" state, and shipping a stub would be WRONG:
   an unresolvable renderer is a case the golden test exercises. Not shipped.
